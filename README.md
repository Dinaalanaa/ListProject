# 🪂 Airdrop Daily

## ✨ Fitur

- 📋 **Multi-tab** — Dashboard, NFT, GALXE, Guild, Waitlist, Random
- ✅ **Status harian** — klik status buat toggle ✔/❌, otomatis update last activity
- 🔄 **Start Daily** — reset semua status sekaligus tiap hari
- ✏️ **Edit & Delete** — ubah atau hapus data kapan aja
- 🖱️ **Drag & Drop** — urutkan project sesuai prioritas
- 📦 **Export JSON** — backup semua data ke file `.json`
- 📂 **Import JSON** — restore data dari backup, cocok buat pindah device
- 💾 **LocalStorage** — data tersimpan di browser, tidak perlu server

## 🚀 Cara Pakai

1. Clone repo ini
```bash
   git clone https://github.com/username/airdrop-daily.git
```
2. Buka `index.html` langsung di browser — tidak perlu install apapun

## 💡 Tips

- Link image diambil dari foto profil project di X (Twitter) — klik kanan → copy image address
- Export rutin buat jaga-jaga kalau ganti browser atau clear cache
- Import file `.json` hasil export buat restore data ke device lain

## 🛠️ Tech Stack

- HTML, CSS, JavaScript (Vanilla)
- LocalStorage API
